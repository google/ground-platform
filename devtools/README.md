# Collect One Developer Tools (`devtools/`)

This directory contains standalone developer and inspection tools for Ground
2.0.

## Tools

-   **[`launchpad/`](launchpad/)**: Browser page for starting, stopping, and
    watching the server, web console, and mobile app (plus the Spanner emulator)
    during local development, with their logs and links to each app.
