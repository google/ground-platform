# ProtoForms XPath Engine (`org.groundplatform.v2.core.forms.xpath`)

A pure Kotlin Multiplatform (KMP) XPath 1.0 + ODK XForms expression parser,
static dependency analyzer, and runtime evaluator designed specifically to
evaluate expressions directly against **ProtoForms** Protocol Buffer messages
(`FormDef`, `RecordInstance`, `RecordNode`, `FieldValue`, and `TypedValue`)
generated by [Square Wire](https://square.github.io/wire/).

--------------------------------------------------------------------------------

## Overview

Unlike legacy XForms engines (such as JavaRosa or Enketo) that evaluate
expressions over untyped XML DOM trees where all answers are serialized strings,
the ProtoForms XPath Engine operates directly on strongly-typed protobuf data
structures defined in the `groundplatform.v2.forms` schema:

-   **Zero XML or Reflection Overhead**: Traverses immutable, code-generated
    Wire protobuf messages using a lightweight, lazy virtual cursor
    (`XPathNode`).

-   **Rich Type Preservation (`XPathValue`)**: Preserves native protobuf types
    (`com.google.type.Date`, `com.google.type.TimeOfDay`,
    `com.squareup.wire.Instant`, `groundplatform.v2.forms.GeoPoint`,
    `groundplatform.v2.forms.GeoTrace`, `groundplatform.v2.forms.GeoShape`, and
    multi-select `ValueList`) across control-flow functions (`if()`, `once()`,
    `coalesce()`) and `calculate_expression` outputs while remaining 100%
    compliant with XPath 1.0 coercion and comparison rules.

-   **Static Dependency Analysis for Reactive Form DAGs**: Extracts field paths,
    secondary instance IDs, and repeat-context dependencies
    (`Set<XPathDependency>`) at compile time from any expression AST to drive
    reactive form recalculations without full-form re-evaluation.

-   **Indexed Equality Pushdown for Secondary Instances**: Provides a pluggable
    `SecondaryInstanceProvider` SPI supporting $O(1)$ / $O(\log N)$ equality
    predicate pushdown (`lookupByEquality`) for `pulldata()` and
    `instance('id')/root/item[key = val]` queries against large offline SQLite
    or IndexedDB Entity Datasets.

## Architecture & Design

### 1. Package Layout

```text

├── CompiledXPathExpression.kt     # AST + static dependency set
├── EvaluationContext.kt           # Record, schema, locale & secondary instance context
├── SecondaryInstanceProvider.kt   # SPI for in-memory or DB-backed secondary instances

├── ast/
│   ├── XPathToken.kt              # Lexer token stream types
│   ├── XPathLexer.kt              # ODK XForms / XPath 1.0 tokenizer
│   ├── XPathAst.kt                # Immutable AST nodes & XPathDependency model
│   ├── XPathParser.kt             # Recursive-descent Pratt parser
│   └── DependencyAnalyzer.kt      # Compile-time dependency extractor
├── model/
│   ├── XPathNode.kt               # Virtual tree cursor over Wire protobuf messages
│   ├── XPathValue.kt              # Rich runtime value ADT & coercion rules
│   └── TemporalUtils.kt           # Civil date/time math, ISO-8601 & strftime formatting
├── eval/
│   └── XPathEvaluator.kt          # AST evaluator & equality predicate pushdown optimizer
└── functions/
    ├── XPathFunctionRegistry.kt   # Complete ODK XForms standard function library
    ├── GeoUtils.kt                # WGS84 Haversine distance, spherical area & geofencing
    └── CryptoAndPrngUtils.kt      # Pure-Kotlin MD5/SHA-1/SHA-256/384/512 & Park-Miller PRNG
```

### 2. Virtual Tree Navigation (`XPathNode`)

Square Wire protobuf messages (`RecordInstance`, `RecordNode`, `FieldValue`) are
immutable and downward-only—child fields have no parent pointers or sibling
indices. To support upward navigation (`..`), 1-based repeat position indices
(`position()`, `last()`), and root schema aliasing (`/data/...` vs
`/household/...`), `XPathNode` wraps protobuf records lazily during evaluation:

-   **`DocumentRootNode`**: Virtual document root `/`.

-   **`InstanceRootElementNode`**: Wraps `RecordInstance.data_` and matches both
    the form's declared root schema name (e.g., `/household/...`) and generic
    XForms `/data/...` paths. Also exposes `<meta>` child nodes backed by
    `RecordInstance.metadata` (`instanceID`, `deviceID`, `timeStart`,
    `timeEnd`).

-   **`GroupOrRepeatNode`**: Wraps nested `RecordNode` groups and unrolls
    `FieldValue.repeat_value` (`RecordNodeList`) items into indexed nodes
    (`repeatIndex = 1..N`, `siblingRepeatCount = N`).

-   **`LeafFieldNode`**: Wraps scalar or multi-select list `FieldValue` leaves.

-   **`SecondaryInstanceNode`**: Wraps lookup table rows for
    `instance('id')/root/item[...]` traversal.

### 3. Rich Runtime Value System (`XPathValue`)

The engine extends XPath 1.0's four classic types (`NodeSet`, `Bool`, `Number`,
`Str`) with first-class ProtoForms types so calculations can pass structured
protobuf values without lossy intermediate string serialization:

`XPathValue` Variant | Underlying Type                    | `toNumber()` Behavior            | `toXPathString()` Behavior
:------------------- | :--------------------------------- | :------------------------------- | :-------------------------
`NodeSet`            | `List<XPathNode>`                  | First node's number (or `NaN`)   | First node's string (or `""`)
`Bool`               | `Boolean`                          | `1.0` / `0.0`                    | `"true"` / `"false"`
`Number`             | `Double`                           | Native IEEE 754 `Double`         | Canonical XPath number string
`Str`                | `String`                           | Parsed number or epoch days      | Raw UTF-8 string
`DateVal`            | `com.google.type.Date`             | Civil days since `1970-01-01`    | `YYYY-MM-DD`
`TimeVal`            | `com.google.type.TimeOfDay`        | Fractional day in `[0.0, 1.0)`   | `HH:MM:SS[.sss]`
`TimestampVal`       | `com.squareup.wire.Instant`        | Fractional days since Unix epoch | ISO-8601 UTC string
`GeoPointVal`        | `groundplatform.v2.forms.GeoPoint` | `NaN`                            | `"lat lon alt acc"`
`GeoTraceVal`        | `groundplatform.v2.forms.GeoTrace` | `NaN`                            | Semicolon-delimited points
`GeoShapeVal`        | `groundplatform.v2.forms.GeoShape` | `NaN`                            | Semicolon-delimited polygon ring
`ValueList`          | `List<XPathValue>`                 | First item's number              | Space-delimited choice tokens

#### Key Type Coercion & Comparison Semantics

1.  **Existential NodeSet Comparisons**: `NodeSet <op> X` evaluates to `true` if
    *any* node in `NodeSet` satisfies `node.extractValue() <op> X`. Per XPath
    1.0 Section 3.4, comparing a `NodeSet` to a `Boolean` (`nodeset = true()`)
    first coerces the `NodeSet` via `toBoolean()`.

2.  **Native Boolean Coercion**: A `NodeSet` containing a single leaf node whose
    protobuf value is `TypedValue(bool_value = false)` coerces to `false` under
    `toBoolean()`, avoiding the XML string pitfall where `boolean("false")`
    evaluates to `true`.

3.  **Native Temporal Comparisons**: Comparing `DateVal` or `TimestampVal`
    against ISO string literals (`'2026-09-17'`) or `today()` parses and
    compares epoch days numerically.

4.  **Lossless Output Conversion**: `XPathValue.toTypedValue(targetType)` and
    `toFieldValue(targetType)` convert computed results back into
    `groundplatform.v2.forms.TypedValue` or `FieldValue` messages for reactive
    `calculate_expression` updates.

## Usage Examples

### 1. Compiling and Evaluating Expressions

Compile an XPath expression once and evaluate it against a `RecordInstance`:

```kotlin
import org.groundplatform.v2.core.forms.xpath.EvaluationContext
import org.groundplatform.v2.core.forms.xpath.XPathEngine
import groundplatform.v2.forms.FieldValue
import groundplatform.v2.forms.RecordInstance
import groundplatform.v2.forms.RecordNode
import groundplatform.v2.forms.TypedValue

val engine = XPathEngine()

// Compile expression once (thread-safe, cacheable)
val isEligibleExpr = engine.compile("/data/age >= 18 and selected(/data/tags, 'consent')")

val recordInstance = RecordInstance(
  schema_id = "survey",
  data_ = RecordNode(
    fields = mapOf(
      "age" to FieldValue(scalar_value = TypedValue(int_value = 24L)),
      "tags" to FieldValue(scalar_value = TypedValue(string_value = "consent verified")),
    )
  ),
)

val context = EvaluationContext(recordInstance = recordInstance)
val isEligible: Boolean = engine.evaluateBoolean(isEligibleExpr, context)
// isEligible == true
```

### 2. Static Dependency Extraction for Reactive Form DAGs

Inspect `CompiledXPathExpression.dependencies` to register listeners in a
reactive form state graph:

```kotlin
import org.groundplatform.v2.core.forms.xpath.ast.XPathDependency

val calcExpr = engine.compile(
  "if(pulldata('villages', 'zone', 'id', /data/village_id) = 'A', position(..), 0)"
)

for (dep in calcExpr.dependencies) {
  when (dep) {
    is XPathDependency.FieldDependency ->
      println("Depends on field path: ${dep.path}") // e.g., /data/village_id
    is XPathDependency.SecondaryInstanceDependency ->
      println("Depends on dataset: ${dep.instanceId}") // e.g., villages
    is XPathDependency.RepeatContextDependency ->
      println("Depends on repeat position/count")
  }
}
```

### 3. Evaluating `calculate_expression` Bindings to `TypedValue`

When updating calculated fields in a `RecordInstance`, evaluate directly to a
`groundplatform.v2.forms.TypedValue` matching the target
`FieldBinding.DataType`:

```kotlin
import groundplatform.v2.forms.FieldBinding

val areaExpr = engine.compile("round(area(/data/plot_boundary), 2)")
val computedValue = engine.evaluateToTypedValue(
  expression = areaExpr,
  context = context,
  targetType = FieldBinding.DataType.DATA_TYPE_DECIMAL,
)
// computedValue.double_value contains the spherical polygon area in square meters
```

### 4. Pluggable Secondary Instance SPI with Equality Pushdown

For large offline datasets stored in SQLite or IndexedDB, implement
`SecondaryInstanceProvider.lookupByEquality` to avoid loading the entire dataset
into memory:

```kotlin
import org.groundplatform.v2.core.forms.xpath.SecondaryInstanceProvider
import org.groundplatform.v2.core.forms.xpath.model.XPathNode
import groundplatform.v2.forms.TypedValue

class SqliteEntityDatasetProvider(private val db: MyDatabase) : SecondaryInstanceProvider {

  override fun lookupByEquality(
    instanceId: String,
    keyField: String,
    keyValue: String,
  ): List<Map<String, TypedValue>> {
    // Executes indexed SQL: SELECT * FROM entities WHERE dataset = ? AND key = ?
    return db.queryEntities(instanceId, keyField, keyValue)
  }

  override fun resolveRoot(instanceId: String): XPathNode? = null
}
```

## Supported ODK XForms Functions

All standard XPath 1.0 and ODK XForms functions are implemented in `commonMain`:

-   **Control Flow & Logic**: `if`, `coalesce`, `once`, `true`, `false`,
    `boolean`, `boolean-from-string`, `not`, `checklist`, `weighted-checklist`.

-   **String Manipulation & Crypto**: `string`, `concat`, `join`, `substr`,
    `substring`, `substring-before`, `substring-after`, `translate`,
    `string-length`, `normalize-space`, `contains`, `starts-with`, `ends-with`,
    `regex`, `uuid`, `digest` (`MD5`, `SHA-1`, `SHA-256`, `SHA-384`, `SHA-512`
    in `hex` or `base64`), `base64-decode`, `pulldata`.

-   **Math & Trigonometry**: `number`, `random`, `int`, `floor`, `ceiling`,
    `round`, `sum`, `min`, `max`, `abs`, `pow`, `sqrt`, `exp`, `exp10`, `log`,
    `log10`, `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, `pi`.

-   **Node-Set & Repeat Navigation**: `count`, `count-non-empty`, `position`,
    `last`, `instance`, `current`, `indexed-repeat`, `randomize` (inside-out
    Fisher-Yates shuffle with Park-Miller seeded PRNG).

-   **Date & Time**: `today`, `now`, `date`, `date-time`, `decimal-date-time`,
    `decimal-time`, `format-date`, `format-date-time`.

-   **Select Lists & Localization**: `selected`, `selected-at`,
    `count-selected`, `jr:itext`, `jr:choice-name`.

-   **Geospatial (WGS84 Ellipsoid / Spherical)**: `distance` (1-arg path length
    and 2-arg point-to-point Haversine distance in meters), `area` (spherical
    excess polygon area in square meters), `geofence` (ray-casting
    point-in-polygon check), `intersects` (polygon segment self-intersection).

## Building and Running Tests

### Java Environment Requirement

Gradle and the Kotlin toolchain require **Java 21**. Set `JAVA_HOME` before
running Gradle commands:

```bash
export JAVA_HOME=/usr/lib/jvm/java-21-openjdk-amd64
```

### Run JVM Unit and Parameterized Tests

To execute all `commonTest` and JUnit 5 `@ParameterizedTest` suites (covering
150+ XPath / ODK XForms expressions evaluated against pure Kotlin ProtoForms DSL
literals):

```bash
./gradlew jvmTest
```

### Run Multiplatform Checks and Compilations

To run the full test suite and verify compilation across JVM, JS, and WasmJS
targets:

```bash
./gradlew check compileKotlinJs compileKotlinWasmJs
```
