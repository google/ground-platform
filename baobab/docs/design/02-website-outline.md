# groundplatform.org Website Outline

## Global Navigation & Sitemap

The website groundplatform.org serves as a lightweight, GitHub-driven, shared
home for technical developers, survey organizers, and field data collectors:

*   **Header Navigation**:
    *   **Features**: Direct link to XLSForm parity, Map-first, Offline
        satellite basemaps.
    *   **Use Cases**: Forest Monitoring (EUDR), Ecosystem Restoration (FERM),
        Smallholder Supply Chains.
    *   **Pricing & Quotas**: Matrix of Basic vs. Sponsored tiers.
    *   **Docs Hub**: Developer Guides and Survey Organizer handbooks.
    *   **Community**: Open Foris Governance Charter, Steering Committee, GitHub
        Repository.
*   **Primary CTA Buttons**:
    *   **"Open Web Console"** (redirects to the cloud-hosted web survey
        designer).
    *   **"Download App"** (direct links to Google Play and Apple App Store).

## Page-by-Page Copy Strategy

## Home Page

*   **Hero Section**:
    *   *Headline*: "Map-Centric, Offline-First Field Data Collection for
        Environmental and Social Impact."
    *   *Sub-headline*: "Now natively on **Android and iOS**. Fully compatible
        with ODK and KoboToolbox schemas."
    *   *Visuals*: A split screen showcasing the Web WYSIWYG editor with live
        mobile and web previews preloading a farm registry next to an active
        mobile screen displaying a walked cocoa perimeter in Ghana with live
        acreage calculations.
*   **The Interoperability Difference**: Section explaining the key value
    propositions:
    *   **We are Map-First**: Traditional apps are form-first; we are built for
        projects where the geographical feature on the map is the primary unit
        of work.
    *   **Zero-Config XLSForm Sync**: Import existing forms instantly.
    *   **Preloaded Entity Registries**: Track subjects longitudinally over
        time.
*   **Trust Logos**: Google, FAO, SERVIR, SIG, YouthMappers.

## Features Page

*   **Pillar 1: WYSIWYG Web Console & Desktop GIS**: No-code visual form editor
    with live mobile and web form previews, versioned surveys and forms,
    in-browser survey data collection, interactive point and polygon drawing and
    vertex editing, entity and submission summary PDF generation and download,
    and administrative dataset governance with complete audit logging and
    version-harmonized data exports.
*   **Pillar 2: Rugged Mobile Client**: Cross-platform shared core, offline
    basemap caching, three native geometry question types, QR code geometry
    capture, on-device entity and submission PDF generation and sharing,
    toggleable geometries, and live area/perimeter/line HUD.
*   **Pillar 3: Data Pipelines & APIs**: Extensible data enrichment hooks, local
    GeoID generation, and REST endpoints for CEO and FERM.

## Use Cases Page

*   **Traceable Supply Chains (Ghana Cocoa & Burundi Coffee)**: Case study copy
    detailing how 21,000 cocoa polygons and 30,000 coffee plots were mapped to
    comply with EUDR regulations.
*   **Ecosystem Restoration & M&E (Kenya & Mauritius)**: Highlighting Nandi
    County's cooperative success, where local farmers achieved 60% mapping
    coverage of their cooperatives in under two months.

## Pricing & Quotas Page

*   **Basic Plan (Free & Self-Service)**: Explicitly details the Basic limits
    (max 5 surveys, 1,000 predefined entities, 10 ACL users) to manage resource
    consumption.
*   **Sponsored Plan (Managed/Institutional)**: Details the Sponsored limits
    (max 100 surveys, 10,000 entities, 50 ACL users), custom basemaps, and
    prioritized support.
*   **Paid Quota Expansion (Roadmap)**: Outlines future self-service options for
    non-profits to purchase additional quota via a foundation-supported payment
    model to scale beyond Basic tier limits.

## Docs Hub & Developer Portal

To eliminate documentation redundancy, this page utilizes a clean markdown
reader that dynamically renders files hosted directly in the GitHub repository:

*   **Survey Organizer Guides**: Form design, schema versioning and draft
    publishing, preloading lookups, audit log inspection, entity and submission
    summary PDF generation, and exporting CSV/GeoJSON datasets with soft-deleted
    question controls.
*   **Data Collector Handbooks**: Offline map caching guides, wayfinding
    checklists, QR code geometry scanning, on-device PDF generation/sharing, and
    external GNSS Bluetooth receiver integration.
*   **Developer & Maintainer Docs**: Consolidated backend deployment,
    cross-platform mobile build guides, and Cloud Marketplace deployment
    scripts.

## Community & Governance Page

*   **Open Foris Governance Charter**: The operational guidelines and bylaws of
    the joint Open Foris framework.
*   **Steering Committee**: Introducing representation from the FAO, Google,
    SERVIR, and regional SMEs.
*   **Get Involved**: Links to Google Groups mailing list, biweekly standup
    notes, and GitHub issues triaged for community contributions.
