Install on iPhone / iPad Download collect-one.ipa
Over-the-air install (Safari on iOS):
  1. Tap Install on iPhone / iPad and confirm the prompt.
  2. On first launch, trust the developer profile in Settings → General → VPN & Device Management.
Install via sideloading:
  1. Download collect-one.ipa.
  2. Install it with AltStore / SideStore, Sideloadly, or Xcode (Window → Devices and Simulators).
No iOS binary is staged in this deployment yet.
iOS binaries require macOS and Xcode. On a Mac, run ./iosApp/scripts/build-ipa.sh and redeploy hosting to publish collect-one.ipa (and collect-one-ios.plist for one-tap Safari installs).
