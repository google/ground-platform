Spanner isn't configured

The user data service connects to Cloud Spanner (or the Spanner emulator) when these environment variables are set:

  • SPANNER_EMULATOR_HOST, e.g. localhost:9010, or SPANNER_INSTANCE_ID for Cloud Spanner
  • Optional: SPANNER_PROJECT_ID (default collect-one-dev), SPANNER_INSTANCE_ID (default dev), SPANNER_DATABASE_ID (default user-data)

To try it locally with the emulator, from the repository root:

scripts/spanner-emulator.sh &
cd server/userDataService
SPANNER_EMULATOR_HOST=localhost:9010 ./gradlew run

On the emulator, the instance and database are created automatically.
